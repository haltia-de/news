# Новости

Новости крупно (`b8k-news`): лента из RSS и Atom, статья читается внутри
программы.

- По умолчанию три петербургские ленты: Интерфакс, Фонтанка, Деловой
  Петербург.
- Текст статьи берётся из ленты, если она несёт его целиком, иначе со
  страницы статьи (JSON-LD `articleBody`, абзацы `itemprop="articleBody"`),
  иначе — краткое содержание из ленты. Кнопка под статьёй открывает полную
  версию в браузере.
- Свои источники: шестерёнка в заголовке — список, удаление и добавление
  ленты или сайта (лента находится через `<link rel="alternate">`, поиск по
  названию и теме — через Feedly и feedsearch.dev). Хранятся в
  `~/.config/b8k/news.conf`.

## Установка

Нужны Python 3, GTK 3 и PyGObject. В Alpine:

```
apk add python3 py3-gobject3 gtk+3.0
```

Поставить в систему (нужен root):

```
sh install.sh            # в /
sh install.sh /mnt/root  # в другой корень, например при сборке образа
```

`install.sh` кладёт программу в `/usr/local/bin/b8k-news`, значки лент и раздел для
панели оболочки в `/usr/local/share/b8k/apps.d/news.conf`.

## Оболочка планшета

Программа сделана для оболочки
[lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux)
(Linux на Lenovo YOGA Tablet 10 B8000-H), её сборка ставит программу
отсюда по тегу. Если в системе есть модуль оболочки
`/usr/local/share/b8k/python/b8k_ui.py`, программа берёт из него вибрацию на нажатия, общий вид заголовка
и открытие статей в Firefox через `b8k-launch` (заставка, одна вкладка на
ссылку).
Без него она работает на любом рабочем столе с GTK 3.
